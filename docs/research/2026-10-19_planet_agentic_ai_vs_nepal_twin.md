# Planet "agentic AI"(ai.planet.com)와 이 지도 — 무엇이 같고, 무엇을 가져올 수 있나 (2026-10-19)

상태: 공개 자료만으로 쓴 외부 제품 비교. 로그인·질의·API 호출은 하지 않았다(베타 약관 PDF가 비밀번호 보호라 자동 접근·공표 제한을 확인하지 못함). 수치 성능 비교 주장 없음.
근거: 동료 공유 메시지(10-15, Imja Tsho 질의 예), 자매 프로젝트 검토 `EO-CVPR/docs/PLANET_AGENTIC_AI_REVIEW_20261019.md`(공개 JS 번들 사실 추출), Planet Pulse·Via Satellite(5/21)·webinar Q&A.

| 항목 | 내용 |

## 2. 이 지도와의 차이 — 한 줄씩
| 축 | Planet agentic AI | 네팔 라이브 트윈(1~3장) |
|---|---|---|
| 센서 | 3 m 광학. **몬순 구름이 있으면 그날은 없다.** 월간 모자이크는 2026-06까지라 8-26·9-29·10-11 사건은 일자 타일로만 | Sentinel-1 레이더(구름·밤 무관) 10 m + Sentinel-2 실색은 보조. 세 사건 모두 사건 당일~며칠 안 레이더가 있었다 |
| 임베딩의 쓰임 | 검색(이것과 비슷한/달라진 곳) | 측정(전 3회 vs 후 1회 거리 Δz) |
| "변했다"의 기준 | 사용자가 정한 유사도 임계값. 거짓경보율 미공개 | **플라시보**(홍수 없던 7~8월 같은 간격) 상위 1% → 정의상 평소 1%만 넘음. M111에서 좌표 사전지식으로 이를 대신하려다 실패 → 플라시보가 핵심 |
| 외부 잣대 | 없음(보고서에 영상 삽입) | Copernicus GFM CSI 0.60, 2024 재실행, 현장 라벨 0개 명시 |
| 타이밍 | 일일 영상이라 원리상 유리. 단 구름 | 12일 궤도 → 10-11은 홍수파보다 6:03에 먼저 지나감(M110). **우리 약점**이고 Planet 일일 광학이 메울 수 있는 자리 |
| 출력 | 채팅·HTML 보고서·cron 알림 | 지도 한 장 + 전후 사진 + 아래 보고서, GeoJSON 다운로드, 확인 요청 메일 |
| 재현성 | 폐쇄 | 공개 영상·공개 가중치·장부 M103~M111 |

Planet이 임베딩을 LLM에 직접 읽히지 않고 검색 도구로 분리한 구조는, 이 지도가 임베딩 거리를 숫자로 뽑고 문장은 사람(또는 LLM)이 쓰는 분업과 같은 방향이다.

## 3. 가져올 수 있는 것 (이 지도 기준, 착수는 사용자 결정)
1. **10-11 부디 간다키 사후 광학 확인(수동, 소)**: 로그인 뒤 Chumchet(84.964, 28.476)·Jagat·Arughat 10-11~10-16 일자 타일을 눈으로 보고, 맑은 날이 있으면 산사태댐 위치 가설(Shyar vs Ungilung) 확정과 하류 진흙 범위 확인. 자동 호출·결과 공표는 약관 확인 전까지 하지 않음. 결과는 장부에 "외부 참고"로만.
2. **라수와 8-26 발원 회랑 교차 확인(수동, 소)**: M99의 "신설 눈" 해석을 3 m 광학으로 재확인.
3. **cron 개념 차용(중)**: Planet식 "AOI + 임계값 + 일일 재계산"을 우리 쪽으로 옮기면 "회랑 + 플라시보 문턱 + 궤도 통과일마다 재계산"이 된다. 이미 계획된 크론(cvpr 목표 (d))과 같은 것. 알림 단위는 구간 등급 변화(normal→some→big, recede/hold).
4. **논문 관련 작업 한 문장**: "상용 agentic EO 비서(Planet)는 광학 유사·변화 검색과 서술 보고서에 머물며, 거짓경보 기준(플라시보)과 외부 잣대(GFM)를 공개하는 공개 스택은 없다." 성능 비교 주장 없이 §1 표를 근거로.
5. **빙하호(동료 질문)**: 이 지도의 레시피는 강 회랑용이지만, 호수 윤곽은 레이더 수역 규칙(VV 낙하)으로 같은 3-vs-1 계약이 가능. Imja·Tsho Rolpa는 구름 없는 10~11월에 광학도 좋으므로 GLOF 쪽은 Planet 일일 광학이 더 맞는 도구. 이 프로젝트 범위 밖, 메모만.
